# Universal Webtoon & Comic Ripper

A powerful, one-click Tampermonkey userscript to extract and download high-quality images from 9 major webcomic platforms across multiple languages

## ✨ Key Features

* **Floating Draggable UI:** Easily access the download controls from a non-intrusive floating menu that can be dragged anywhere on the screen
* **Automated Folder Organization:** Automatically names and sorts individual downloaded images into separate folders based on the chapter title (note: ZIP generation is not supported)
* **Concurrent Downloading:** Utilizes up to 4 parallel workers in the background to maximize download speed
* **Smart Auto-Scroll (Mangatoon VN):** Includes a dedicated "Auto Scroll" button specifically for `mangatooncom.vn` to ensure lazy-loaded images are fully rendered before extraction

## 🌐 Supported Platforms & Languages

This script is configured to work across the global and regional subdomains of the following platforms

| Platform | Supported Languages
| :--- | :--- |
| **Webtoon** | English, 中文 (繁體), ภาษาไทย, Indonesia, Español, Français, Deutsch |
| **Mangatoon** | English, Indonesia, Tiếng Việt, Español, Português, ไทย, Français, Deutsch, Italiano, العربية |
| **Lalatoon** | English, 中文(简体), 中文(繁體), Español(LA), Español(ES), Italiano, Português, Deutsch, Français, 日本語, 한국어 |
| **Honeytoon** | English, Français, Deutsch, Español, Português, Italiano, Chinese |
| **Toomics** | English, 中文(简体), 中文(繁體), Español, Italiano, Português, Deutsch, Français, 日本語, ภาษาไทย, 한국어 |
| **Toptoon** | English, Korean, Chinese |

*(Full support also included for Tapas, Naver, and Dongmanmanhua)

## 🚀 Installation & Usage

1. **Prerequisite:** Install a userscript manager. **Tampermonkey** is highly recommended
2. **Install the Script:** Download the latest version (v1.0.4) from my [Greasyfork Profile]([https://greasyfork.org/en/users/1553223-ozler365](https://greasyfork.org/en/scripts/594644-tapas-webtoon-mangatoon-toomics-naver-dongmanmanhua-lalatoon-honeytoon-toptoon-ripper-all-languages))
3. **Usage:** 
   * Navigate to any supported comic chapter.
   * Click the green **Extract & Download** button on the floating UI to queue and download the images
   * The UI will track your total image count, successful downloads, and failures in real-time
